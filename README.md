# Customer Shopping Behavior Analysis 🛒📊

## 📌 Project Overview
This project analyzes customer shopping behavior to uncover meaningful insights related to purchasing patterns, customer demographics, subscription status, and product performance.
The goal is to help businesses make data-driven decisions to improve revenue, customer retention, and marketing strategies.

---

## 🎯 Objectives
- Understand customer purchasing behavior
- Analyze revenue and sales across product categories
- Segment customers by age group and subscription status
- Identify high-value customer groups
- Visualize insights using an interactive Power BI dashboard

---

## 🛠️ Tools & Technologies Used
- Python (Pandas)
- SQL (MySQL)
- Power BI
- Jupyter Notebook
- GitHub

## 🔍 Key Analysis Performed

### Data Cleaning & Feature Engineering (Python)
- Handled missing and inconsistent values
- Created new features such as Age Group
- Removed unnecessary columns
- Prepared clean data for analysis and visualization

### SQL Analysis
- Revenue comparison by gender
- Customer segmentation by age group
- Subscription vs non-subscription analysis
- Purchase frequency and spending behavior
- Category-wise sales and revenue insights

### Power BI Dashboard
- KPIs: Total Customers, Average Rating, Average Purchase Amount
- Revenue & Sales by Category
- Revenue & Sales by Age Group
- Subscription Status Distribution
- Interactive filters for gender, category, and shipping type

---

## 📈 Key Insights
- Middle-aged customers generate the highest revenue
- Subscription-based customers show higher purchase frequency
- Clothing category contributes the most to total sales
- Young adults have comparatively lower average spending
- Subscription customers are more consistent buyers

---

## 💡 Business Recommendations
- Focus marketing campaigns on middle-aged customers
- Promote subscription plans to increase repeat purchases
- Invest more in high-performing categories like Clothing
- Create targeted offers for young adults to increase spending
